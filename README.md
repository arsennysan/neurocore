# NEURO//CORE

Футуристичный симулятор нейрона на модели Ходжкина–Хаксли (1952).

Автор: **arsenomen**

## Что внутри
- Живой нейрон: ионы Na⁺ и K⁺, воротные переменные m, h, n, сальтаторное проведение
- Осциллограф, ионные токи, растр спайков, звук спайков
- Фармакология: TTX, TEA, лидокаин, гиперкалиемия
- Режимы «Нейрон», «Синапс» и конструктор сети до 12 нейронов
- Клиника: 4 пациента (отравление фугу, гиперкалиемия, рассеянный склероз, эпилепсия)
- Головоломки «собери сеть»: провод, ретранслятор, ИЛИ, И, эхо-память
- 13 миссий в 3 уровнях со званиями, обучение для новичков

## Запуск
